Banco de dados, monitoramento e backup

Banco de dados na nuvem (Supabase)

Com o Supabase configurado, os dados ficam salvos na nuvem e são compartilhados por toda a equipe, com login. Sem ele, os dados ficam só neste navegador. O ideal é preencher em config.js, o que vale para todos. Os campos abaixo valem só para este navegador.

Financeiro

Faturamento mensal médio da empresa. É a base do cálculo de churn no Dashboard CS (churn = faturamento do cliente ÷ esta base).

Avisos por e-mail · aviso prévio

Toda vez que uma nova solicitação de saída (aviso prévio) for cadastrada no CS, um e-mail com os dados do cliente é enviado automaticamente de arthurrocha@orioncloudkitchens.com.br para os endereços abaixo.

Conexão com o Gmail (Google Apps Script)Ocultar conexão
  1. Entre em script.google.com com a conta arthurrocha@orioncloudkitchens.com.br e crie um projeto.
  2. Apague o conteúdo do editor e cole o código do arquivo automacoes/email-aviso-previo.gs do projeto.
  3. Clique em Implantar → Nova implantação, escolha o tipo App da Web, Executar como: eu e Quem pode acessar: qualquer pessoa. Autorize o acesso ao Gmail.
  4. Copie o URL do app da Web e cole abaixo.

O endereço fica guardado numa área protegida do banco e não aparece no site.

Monitoramento dos sistemas

Defina como cada serviço é verificado. Manual: a equipe marca o status na tela. HTTP: a URL precisa responder 2xx e permitir CORS. Alcance: só verifica se a URL responde. Campo JSON: compara um campo da resposta (ex.: data.aberto = true). Heartbeat: o sistema externo envia um sinal periódico (veja abaixo).
